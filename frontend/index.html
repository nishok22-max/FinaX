One transaction, or no transaction

Contract-enforced atomicity

These steps execute inside a single on-chain transaction. If any step fails the HealthGuard check, the entire transaction reverts and the position is left byte-for-byte unchanged — proven by 13/13 passing Foundry fork tests.

Mandate tuning

Requires a new borrower signature

The agent can suggest a different mandate but cannot apply one. A registered RiskParams is EIP-712 signed by the borrower; changing any field invalidates the signature and the vault reverts BadSignature.
